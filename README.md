# Brain Rot

Fun additions for **Batomon Showdown**. Brain Rot watches your run and battle as
you play and celebrates the moments that deserve a reaction.

## Features

### Reactions
- Tracks run and battle state in real time and fires reactions as you play.
- Each reaction shows a themed toast in the bottom-right corner, with its own
  icon and sound.

### Memories
- Tracks your best results across a set of battle metrics.
- A "Memories" button in the shop opens a panel showing your personal records,
  including when each was set.

### Auto-update
- Checks GitHub releases on game start and installs new versions automatically.

### Settings
- **Mod Volume** — a slider under Settings > Mods that controls the volume of
  the sounds this mod plays.


REQUIREMENTS
------------
- Batomon Showdown (Steam, PC)
- Community Batomon Showdown Mod Loader

IMPORTANT: The community Mod Loader is REQUIRED and must be installed before Brain Rot.

Mod Loader by EmoUsedHM01 and madibye (separate download).


INSTALLATION
------------
1. Install the community Batomon Showdown Mod Loader first.
   Follow the installation instructions on its Nexus Mods page.

2. Close Batomon Showdown.

3. Locate your game installation folder:
   Steam > Right-click Batomon Showdown > Manage > Browse local files

4. Extract the Brain Rot ZIP into the game folder, preserving the folder structure.

   The resulting structure should look like:

   Batomon Showdown\Mods\BrainRot\
      mod_main.gd
      mod.json
      ...additional mod files and assets...

   IMPORTANT:
   - Do not create an extra nested BrainRot folder.
   - mod_main.gd and mod.json must be directly inside Mods\BrainRot\.

5. Launch Batomon Showdown.

The Mod Loader should automatically detect Brain Rot.


UNINSTALLATION
--------------
1. Close Batomon Showdown.
2. Delete the folder:

   Batomon Showdown\Mods\BrainRot

3. Launch the game normally.

Brain Rot does not modify game saves or permanent gameplay data. Uninstalling does not require starting a new run.


COMPATIBILITY & TROUBLESHOOTING
-------------------------------
Brain Rot is designed to work alongside other mods using the community Mod Loader, but compatibility with every mod is not guaranteed.

If the mod does not appear:
- Confirm the Mod Loader is installed and working.
- Verify the folder structure shown above.
- Restart the game.

If you encounter a bug, please include a description, reproduction steps, and screenshots if possible.
