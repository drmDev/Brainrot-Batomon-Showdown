# Brain Rot

Fun additions for **Batomon Showdown**. Brain Rot watches your run and battle as
you play and celebrates the moments that deserve a reaction.

## Features

### Reactions
- Tracks run and battle state in real time and fires reactions as you play.
- Each reaction shows a themed toast in the bottom-right corner, with its own
  icon and sound.

### Memories
- Tracks your best results across a set of battle metrics.
- A "Memories" button in the shop opens a panel showing your personal records,
  including when each was set.

### Auto-update
- Checks GitHub releases on game start and installs new versions automatically.

## Settings

- **Mod Volume** — a slider under Settings > Mods that controls the volume of
  the sounds this mod plays.
